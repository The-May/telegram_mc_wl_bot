# How to:


## Installation/Preparation:

0. (go to your dir where your MC server is before)
1. **git clone https://github.com/The-May/telegram_mc_wl_bot.git** 
2. **cd telegram_mc_wl_bot**
3. have **python3** installed and **python3-venv** -> run -> **python3 venv -m venv** -> **source venv/bin/activate** -> make sure you have (venv) activated -> **python3 pip install python-telegram-bot mcrcon python-dotenv** -> exit the venv
4. edit .env file acordingly -> see comments
5. create bot with **@botfather**, allow via botfather to add this bot to groups, invite bot to group, disable via botfather to allow adding this bot to group to prevent messing around and making it securer for good.
6. write /start, read out from the created logfile from the bot and apply the CHAT IT and change accordingly
7. copy system unit file and change accordingly -> **read comments**
8. start unit with **systemctl start whitelistbot** and hope it works
